# Image Upload Instructions

To see your images in the application, please place the following files in this `public` folder:

1.  `original.jpg` - The original input image.
2.  `encrypted.jpg` - The encrypted version of the image.
3.  `embedded.jpg` - The image with data embedded.
4.  `recovered.jpg` - The recovered image.

The application is configured to look for these exact filenames.
